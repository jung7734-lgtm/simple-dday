# 심플 D-Day 앱

날짜 추가, D-Day 자동 계산, 삭제만 포함한 가족 응원 문구를 더한 귀여운 모바일 웹 앱(PWA)입니다.

## 포함 기능
- 기본 일정: **수능 : 정서희 — 2026년 11월 19일**
- 남은 날짜 자동 계산 (D-51처럼 표시)
- 일정 추가 및 삭제
- 기기 브라우저에 일정 저장
- PWA 홈 화면 설치 및 오프라인 캐시 지원

## 실행 및 설치
PWA 설치를 위해서는 HTTPS로 제공되는 웹 주소가 필요합니다. `index.html` 파일을 단순히 파일 앱에서 여는 것만으로는 홈 화면 설치 기능이 작동하지 않을 수 있습니다.

1. 이 ZIP 파일의 압축을 풉니다.
2. 폴더 안의 파일 전체를 HTTPS를 지원하는 정적 웹 호스팅에 올립니다 (예: GitHub Pages).
3. 사이트 주소를 휴대전화 브라우저로 엽니다.
4. **iPhone:** Safari의 공유 버튼 → '홈 화면에 추가'
5. **Android:** Chrome 메뉴 → '앱 설치' 또는 '홈 화면에 추가'

## 참고
- 일정은 서버가 아니라 해당 브라우저/기기에 저장됩니다. 다른 기기와 자동 동기화되지는 않습니다.
- 브라우저 데이터 삭제 시 저장한 일정이 사라질 수 있습니다.
- 날짜 계산은 기기의 현지 날짜 기준입니다.
